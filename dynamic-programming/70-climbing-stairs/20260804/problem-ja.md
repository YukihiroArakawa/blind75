# 70. 階段を上る

難易度: Easy

## 問題

あなたは階段を上っています。頂上に到達するには `n` 段上る必要があります。

1 回で `1` 段または `2` 段上ることができます。頂上に到達する方法は何通りありますか。

## 例

### 例 1

```text
入力: n = 2
出力: 2
説明: 頂上に到達する方法は 2 通りあります。
1. 1 段 + 1 段
2. 2 段
```

### 例 2

```text
入力: n = 3
出力: 3
説明: 頂上に到達する方法は 3 通りあります。
1. 1 段 + 1 段 + 1 段
2. 1 段 + 2 段
3. 2 段 + 1 段
```

## 制約

- `1 <= n <= 45`
