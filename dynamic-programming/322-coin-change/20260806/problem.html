LEETCODE 322 · DYNAMIC PROGRAMMING

Coin Change

与えられた金額を作るために必要な硬貨の枚数を、最小にします。

難易度: Medium

問題

異なる額面の硬貨を表す整数配列 coins と、合計金額を表す整数 amount が与えられます。

その金額を作るために必要な硬貨の枚数のうち、最も少ない枚数を返してください。どの硬貨の組み合わせでも金額を作れない場合は -1 を返します。

各額面の硬貨は無限に使えるものとします。

例

例 1

入力coins = [1,2,5], amount = 11出力3
11 = 5 + 5 + 1 と作れるため、必要な硬貨は 3 枚です。

例 2

入力coins = [2], amount = 3出力-1
額面 2 の硬貨だけでは 3 を作れません。

例 3

入力coins = [1], amount = 0出力0
金額が 0 のとき、硬貨を使う必要はありません。

制約

  • 1 <= coins.length <= 12
  • 1 <= coins[i] <= 231 - 1
  • 0 <= amount <= 104
