# 48. 画像の回転

難易度: Medium

## 問題

画像を表す `n x n` の 2 次元配列 `matrix` が与えられます。この画像を **時計回りに 90 度回転** させてください。

この回転は **in-place** で行う必要があります。つまり、入力の 2 次元配列 `matrix` 自体を書き換えなければならず、別の 2 次元配列を新しく確保して回転してはいけません。

## 例

**例 1:**

```text
入力: matrix = [[1,2,3],[4,5,6],[7,8,9]]
出力: [[7,4,1],[8,5,2],[9,6,3]]
```

**例 2:**

```text
入力: matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
出力: [[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

## 制約

- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 備考

- 行列は必ず正方形です。
- 返り値はなく、`matrix` を直接回転後の状態へ更新します。
