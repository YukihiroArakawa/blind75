# 79. 単語探索

難易度: Medium

## 問題

文字の `m x n` グリッド `board` と文字列 `word` が与えられます。`word` がグリッド内に存在するなら `true` を返してください。

単語は、連続して隣接するマスの文字をつなげて構成されます。隣接とは上下左右に接していることを意味します。同じマスは 1 回しか使えません。

## 例

**例 1:**

```text
入力: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
出力: true
```

**例 2:**

```text
入力: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
出力: true
```

**例 3:**

```text
入力: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
出力: false
```

## 制約

- `m == board.length`
- `n == board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` と `word` は英小文字および英大文字のみで構成されます。

## 発展

- `board` が大きい場合でも、探索の枝刈りを使ってより高速にできますか。
