# 190. ビット反転

難易度: Easy

## 問題

与えられた 32 ビットの符号付き整数のビット列を反転してください。

## 例

### 例 1

**入力:** `n = 43261596`

**出力:** `964176192`

**説明:**

| 整数 | 2 進表現 |
| --- | --- |
| `43261596` | `00000010100101000001111010011100` |
| `964176192` | `00111001011110000010100101000000` |

### 例 2

**入力:** `n = 2147483644`

**出力:** `1073741822`

**説明:**

| 整数 | 2 進表現 |
| --- | --- |
| `2147483644` | `01111111111111111111111111111100` |
| `1073741822` | `00111111111111111111111111111110` |

## 制約

- `0 <= n <= 2^31 - 2`
- `n` は偶数です。

## 発展

この関数が非常に多く呼ばれる場合、どのように最適化しますか。
