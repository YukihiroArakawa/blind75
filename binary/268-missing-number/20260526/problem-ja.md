# 268. 欠けている数

難易度: Easy

## 問題

`[0, n]` の範囲にある `n` 個の異なる数を含む配列 `nums` が与えられます。配列から欠けている、その範囲内のただ 1 つの数を返してください。

## 例

### 例 1

**入力:** `nums = [3,0,1]`

**出力:** `2`

**説明:**

数は 3 個あるので `n = 3` です。したがって、すべての数は `[0,3]` の範囲にあります。`2` は `nums` に現れないため、この範囲で欠けている数です。

### 例 2

**入力:** `nums = [0,1]`

**出力:** `2`

**説明:**

数は 2 個あるので `n = 2` です。したがって、すべての数は `[0,2]` の範囲にあります。`2` は `nums` に現れないため、この範囲で欠けている数です。

### 例 3

**入力:** `nums = [9,6,4,2,3,5,7,0,1]`

**出力:** `8`

**説明:**

数は 9 個あるので `n = 9` です。したがって、すべての数は `[0,9]` の範囲にあります。`8` は `nums` に現れないため、この範囲で欠けている数です。

## 制約

- `n == nums.length`
- `1 <= n <= 10^4`
- `0 <= nums[i] <= n`
- `nums` のすべての数は **一意** です。

## 発展

追加の空間計算量が `O(1)`、実行時間計算量が `O(n)` の解法を実装できますか。
