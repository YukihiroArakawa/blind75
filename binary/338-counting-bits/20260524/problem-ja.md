# 338. ビット数え上げ

難易度: Easy

## 問題

整数 `n` が与えられます。長さ `n + 1` の配列 `ans` を返してください。各 `i` (`0 <= i <= n`) について、`ans[i]` は `i` の 2 進表現に含まれる `1` の個数です。

## 例

**例 1:**

```text
入力: n = 2
出力: [0,1,1]
説明:
0 --> 0
1 --> 1
2 --> 10
```

**例 2:**

```text
入力: n = 5
出力: [0,1,1,2,1,2]
説明:
0 --> 0
1 --> 1
2 --> 10
3 --> 11
4 --> 100
5 --> 101
```

## 制約

- `0 <= n <= 10^5`

## 発展

- 実行時間 `O(n log n)` の解法は比較的簡単に思いつきます。これを線形時間 `O(n)`、できれば 1 パスで解けますか？
- 組み込み関数（たとえば C++ の `__builtin_popcount`）を使わずに解けますか？
